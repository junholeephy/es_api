서버 메모리에 유지해 클러스터 자원을 더 많이 씁니다. (8.15.3에서 scroll은 여전히 **동작합니다.**)

어떻게 진행할까요?

A) 요청하신 대로 **scroll API**를 사용 (기존 코드/사내 관례와 맞춰야 하는 경우)

B) **`search_after` + PIT**로 구현 (ES 8.x 권장 방식, 자원 효율이 좋음)

C) **둘 다 구현**하고 설정으로 선택 (기본값은 scroll)

X) Other (아래 [Answer]: 뒤에 직접 설명해 주세요)

[Answer]: A
